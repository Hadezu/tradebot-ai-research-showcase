# Current status and roadmap

**Private Research Project — Active Development**

In plain English: the software foundation for research has been built and tested in a defined scope. It can run controlled experiments, compare models and reject ones that lack evidence. We have not shown that it can earn money consistently. Learning how to choose better trades and manage them remains ongoing work.

The table below gives the more technical breakdown.

Status vocabulary: IMPLEMENTED means code exists; VERIFIED means a stated behavior has reproducible test evidence; EXPERIMENTAL means research use; IN PROGRESS means incomplete work; NOT VERIFIED means insufficient evidence. Verification is scoped to the tested version and conditions.

| Capability | Status | Boundary |
|---|---|---|
| Historical data and native/exploratory candidates | IMPLEMENTED / scoped VERIFIED | Not every apparent opportunity is executable. |
| Causal historical accounting and risk checks | scoped VERIFIED | Simulation assumptions still matter. |
| Version-bound labels and model interfaces | scoped VERIFIED | An incompatible candidate must be rejected. |
| Training, saving, loading and supported recovery | scoped VERIFIED | Unproven saves fail closed. |
| Entry model selection | EXPERIMENTAL | Reliable economic advantage NOT VERIFIED. |
| Learned hold/close selection | EXPERIMENTAL | Existing candidate has not demonstrated an advantage. |
| Protection changes and partial reductions | Execution/target interfaces scoped VERIFIED | Trained approved selection IN PROGRESS. |
| Sustained profitability | NOT VERIFIED | No public performance claim. |

## Next research priorities

Evaluate whether information available before a decision supports useful selection after modelled costs. Compare candidates and baselines chronologically, preserve rejected experiments and keep independent future evaluation separate from model development. Investigate management decisions under compatible outcome definitions.

The technical foundation enables these studies; it does not guarantee a positive result. Abstaining from trading remains a valid outcome. No deployment follows automatically from a successful experiment.
